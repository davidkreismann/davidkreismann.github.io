CHECK24 besteht aus vielen unabhängigen Produktbereichen wie Flügen, Hotels, Pauschalreisen und Ferienwohnungen. Jeder Bereich hat einen eigenen MCP-Server mit eigenen Tools. Dieses Projekt stellt einen einzigen MCP-Proxy vor alle diese Bereiche. Es war mein Beitrag zur CHECK24 GenDev Scholarship Challenge, für den ich das GenDev IT-Stipendium erhalten habe.

**Stack:** TypeScript, Next.js 15, MCP TypeScript SDK, Zod, Monorepo mit pnpm und Turbo, GitHub Actions, Vercel
